Design System for a Wealth Managment Company


Organization: Accenture

Term: Summer 2023

Type: UX Design

Skills: Components, Scalable Design, Design system

Tools: Figma


Problem definition

UX consulting team was contracted to build out new features for a product for a wealth management company. They wanted to improve their documentation and reduce the time designers spent making wireframes and mockups.

Project Goals

  • Reduce time spent by designers on the project by creating a design system for the new product.
  • Improve the documentation for the product.

Requirements and Constraints

  • Design system documentation must be stored in Figma
  • Documentation must include accessibility and usage guidelines
  • Design system must incorporate and follow existing guidelines

Method

  • 1. Research similar product's design system and design system structure
  • 2. Make wireframes of the documentation
  • 3. Build scalable documentation
  • 4. Build components
